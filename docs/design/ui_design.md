### 売上表示画面

#### レイアウト
```
+---------------------------------------------+
|  売上表示                  年選択: [2025▼] |
+---------------------------------------------+
|  月別売上合計表示                         |
|  +------+----------+----------+----------+  |
|  | 年月  | 販売員合計 | 委託先合計 | 総合計   |  |
|  +------+----------+----------+----------+  |
|  | 1月  | ¥1,500,000| ¥800,000 |¥2,300,000|  |
|  | 2月  | ¥1,200,000| ¥650,000 |¥1,850,000|  |
|  |  ... |    ...   |    ...   |    ...   |  |
|  +------+----------+----------+----------+  |
|  [月をクリックすると商品別数量表示に切り替わる]    |
+---------------------------------------------+
|  2025年1月 商品別数量合計           [←戻る]   |
|  +------------------+------+------+------+  |
|  | 商品名           |販売員 |委託先|合計  |  |
|  +------------------+------+------+------+  |
|  | 商品A           |  120 |   50 |  170 |  |
|  | 商品B           |   80 |   30 |  110 |  |
|  |  ...             |  ... |  ... |  ... |  |
|  +------------------+------+------+------+  |
+---------------------------------------------+
```

#### インタラクション
- **年選択**: ドロップダウンで年を切り替えると月別合計表を再読み込み
- **月行クリック**: 月別合計表の行をクリックするとその月の商品別数量表を表示
- **戻るボタン**: 商品別数量表から月別合計表に戻る
- 月行の背景色をハイライトでアクティブ状態を視覚化

#### テーブル仕様
- 総合計列は太字・強調表示
- 金額は右寄せでカンマ区切り表示（例: ¥1,500,000）
- 販売員請求書が0円の月は「—」表示
- 委託先請求書が0円の月は「—」表示
- モバイルでは横スクロール対応

## 5. コンポーネント設計
- **ボタン**: プライマリ、セカンダリ、危険ボタン
- **フォーム**: テキスト入力、数値入力、日付ピッカー、オートコンプリート
- **テーブル**: ソート可能、ページネーション付き
- **モーダル**: 確認ダイアログ、詳細表示
- **通知**: トーストメッセージ

## 6. カラースキーム
- プライマリ: 青系 (#3B82F6)
- セカンダリ: グレー系 (#6B7280)
- アクセント: 緑系 (成功)、赤系 (エラー)
- 背景: 白/ライトグレー

## 7. タイポグラフィ
- フォント: システムフォント（San Francisco, Roboto等）
- サイズ: 16px (本文), 18px (見出し), 24px (タイトル)
- 行間: 1.6
